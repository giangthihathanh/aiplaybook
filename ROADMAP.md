# AI Test Manager Hub Roadmap

## Completed

### v1.0 Foundation
- AI Playbook, Combined Catalog, 3 POCs, 12 use cases and Prompt Registry.
- Vite + React website and GitHub Pages deployment.

### v1.1 Sprint 1, Usability
- Home inventory and honest readiness dashboard.
- Use Case search and filtering.
- JSON-driven Prompt Registry.
- Documentation Center and POC readiness views.

### v1.2 Sprint 2, Governance
- Governance Center, lifecycle and human review gates G1 to G5.
- RACI, scale checklist, incident template and semantic change control.

### v1.3 Sprint 3, Repository Operations
- Security policy, Code Owners template, issue forms, pull-request control and release checklist.
- Repository validation scripts and documented contribution flow.

### v1.4 Sprint 4, Quality
- Accessibility improvements, mobile and table behavior, error and empty states.
- Asset/link checks, JSON checks, production build checks and quality checklist.

## Next candidates

### v1.5 Evidence Integration
- Import approved POC evidence summaries.
- Replace readiness placeholders with source-backed KPI values.
- Add evidence freshness and provenance indicators.

### v1.6 Reporting Integration
- Connect approved Power BI or governed data export.
- Add drill-through from portfolio KPI to POC and evidence record.

### v2.0 Controlled Enterprise Integration
- SSO, role-based access, controlled storage and audit integration.
- Integrations require organizational approval and are not committed to this public template.
