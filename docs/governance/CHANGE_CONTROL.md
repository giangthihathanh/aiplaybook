# Prompt and Workflow Change Control

## Versioning

- **Major:** changed objective, decision policy, output contract or risk profile.
- **Minor:** new supported scenario, field or control that changes behavior.
- **Patch:** non-behavioral clarification, typo or formatting correction.

## Required change record

- Asset ID and old/new version
- Reason and requested owner
- Related use cases
- Data classification impact
- Changed input/output contract
- Evaluation set executed
- Comparison with previous version
- New failure modes
- Human reviewer and approval
- Effective date and rollback version
