## Hero description

A contributor-owned QA knowledge collection containing reusable prompts, technical learning paths, automation guidance, Elasticsearch DSL references, career roadmaps, practical tools, and supporting guides. The collection is preserved locally with permission for public reference while retaining the original author, ownership, and source links.

## Primary actions

- **Open Local Knowledge Hub**: Opens the locally retained Prompt Library and QA reference collection.
- **Open External Prompt Library**: Opens the original public Prompt Library website.
- **View Attribution**: Displays author, source, permission scope, and ownership notice.

## Knowledge collections

### Prompt Library

A searchable collection of reusable prompts covering QA architecture, test strategy, requirement and specification review, test design, analysis, data engineering, Oracle-related tasks, QA management, performance, and security topics.

**Use when:** exploring prompt patterns, comparing prompt structures, or accelerating a first draft.  
**Control:** verify the prompt against the current project context, data classification, and human review requirements before operational use.  
**Action label:** Open Prompt Library

### Prompt Library Guide

Guidance for browsing, searching, filtering, copying, favoriting, editing, comparing, and sharing prompt content.

**Use when:** onboarding a new user to the community Prompt Library.  
**Action label:** Open User Guide

### Playwright Learning

Core references and a phased learning roadmap for Playwright, Python, Pytest, automation architecture, and CI/CD adoption.

**Use when:** developing or extending browser automation capability.  
**Expected progression:** language and test fundamentals, Playwright core, Pytest practices, framework design, CI/CD, and advanced maintainability.  
**Action labels:** Open Playwright Core; Open Playwright Roadmap

### Katalon Learning

A structured roadmap for Katalon Studio, including foundational usage, test organization, maintainability, custom keywords, listeners, execution, and learning resources.

**Use when:** onboarding testers to Katalon or standardizing capability development.  
**Action label:** Open Katalon Roadmap

### Elasticsearch Query DSL

A handbook and multiple learning editions covering Elasticsearch Query DSL concepts, practical examples, query composition, filtering, aggregation, troubleshooting, and progressive exercises.

**Use when:** learning or reviewing Query DSL used in data validation, observability, search, and test-data analysis.  
**Action labels:** Open DSL Handbook; Open Latest DSL Learning Edition; View Earlier Editions

### Kibana DSL Converter

A local utility supporting Kibana URL and Elasticsearch DSL conversion, formatting, comparison, copy, and share-state scenarios.

**Use when:** converting or reviewing query content during dashboard, search, or data-validation work.  
**Control:** validate converted queries in a safe non-production environment and review index, permission, and performance impact.  
**Action label:** Open DSL Converter

### Career Roadmaps

Professional development roadmaps for QA and engineering growth, including dependencies and possible development tracks such as SDET, DevOps, AI/ML, Security, and Leadership.

**Use when:** discussing individual learning goals or capability planning.  
**Action label:** Open Career Roadmap

### Harness Chatbot Flow

A technical flow reference using visual diagrams to describe chatbot and platform interactions.

**Use when:** reviewing technical process flow, integration points, or architecture discussions.  
**Action label:** Open Harness Chatbot Flow

### Attribution and Source

Author, source, license or permission information, archive scope, and content ownership statement.

**Use when:** reviewing publication permission, repository governance, or source provenance.  
**Action labels:** View Attribution; Open Original Source
