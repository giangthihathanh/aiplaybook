# Governance RACI

**R = Responsible, A = Accountable, C = Consulted, I = Informed**

| Activity | Sponsor / QA Director | Program Lead | POC Lead | Prompt Owner | QA Reviewer | Engineer | Product / BA | Security / Privacy | Release Manager |
|---|---|---|---|---|---|---|---|---|---|
| Approve scope and budget | A | R | C | C | I | I | C | C | C |
| Define KPI contract | C | A | R | C | R | C | C | C | C |
| Approve tool and classification | I | C | C | C | I | C | I | A/R | I |
| Develop and evaluate workflow | I | A | C | R | R | R | C | C | I |
| Approve generated QA artifact | I | I | A | C | R | C | C | C | I |
| Approve release recommendation | I | I | C | C | C | I | C | C | A/R |
| Investigate control incident | I | A | R | C | R | R | C | R | C |
| Approve controlled use | C | A | R | C | R | C | C | C | C |
| Approve scale | A | R | C | C | C | C | C | C | C |
| Suspend or retire | A | R | C | R | C | C | C | C | C |
